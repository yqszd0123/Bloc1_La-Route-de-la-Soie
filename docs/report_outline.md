# Structure du Engineering Data Report

1. objectif et périmètre ;
2. architecture IFC/STEP/manuelle ;
3. sources normatives, fabricants et open source ;
4. catalogue acier et contrôles de masse ;
5. règles géométriques et ouvertures ;
6. optimisation et résultats du cas de référence ;
7. coût par défaut et saisie facultative ;
8. paquet de fabrication et interface Bloc 1 → Bloc 2 ;
9. essais automatisés et vérifications croisées ;
10. limites, données Avelis manquantes et décisions requises.
