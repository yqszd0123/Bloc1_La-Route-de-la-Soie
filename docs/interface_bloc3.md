# Interface Bloc 1 → Bloc 3 logistique

Le JSON `avelis.logistics.wall-handover.v2` fournit le projet, le candidat, tous les IDs, la masse acier calculée, l’enveloppe du panneau et la règle de traçabilité QR. Bloc 3 doit compléter : enveloppe transport, masse maximale de colis, orientation de stockage, ordre de livraison et retour dommage.

La masse provient des mêmes composants que la BOM ; elle n’inclut ni fixations, ni parements, ni emballage tant que ces éléments ne sont pas modélisés.
