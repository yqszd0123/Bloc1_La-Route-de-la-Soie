# Interface Noov proposée

Entrée : `avelis.noov.wall-configuration.request.v2`. Elle contient identité, provenance MANUAL/IFC/STEP, enveloppe, placement, ouvertures et objectif. Sortie : `avelis.noov.wall-design.response.v2`, avec candidat, score, métriques, composants, validation et limites.

Ces noms ne sont pas un contrat Noov confirmé. L’authentification, le transport, le versionnement, les erreurs et le schéma officiel restent à fournir. Le projet conserve donc le statut `INTERFACE_PROPOSAL_NOT_OFFICIAL_NOOV_FORMAT`.
